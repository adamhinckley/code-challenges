# Code Challenges

A collection of TypeScript coding challenges for practicing algorithms, data structures, and real-world programming patterns.

## Prerequisites

- Node.js (v16 or higher)
- pnpm (or npm/yarn)

## Installation

Install dependencies:

```bash
pnpm install
```

Or with npm:

```bash
npm install
```

## Running Challenges

### Watch Mode (Recommended)

Run a challenge with auto-reload on file changes:

```bash
pnpm watch challenges/<filename>
```

Example:

```bash
pnpm watch challenges/combineData.ts
```

### One-Time Execution

Run a challenge once without watching:

```bash
npx tsx challenges/<filename>
```

Example:

```bash
npx tsx challenges/combineData.ts
```
